# SpecToPR 가이드

이 디렉터리는 SpecToPR Lite의 한국어 문서 사이트입니다.

## 다루는 내용

- 시작 전 준비와 설치
- `brief`, `feature`, `figma`, `legacy` 케이스별 사용법
- 현재 진행 방식과 화면 비교·Gap 원칙
- 한국어 Draft PR 형식과 문제 해결

## 로컬 확인

```bash
pnpm install --frozen-lockfile
pnpm build
```

`main`에 가이드 변경이 반영되면 GitHub Pages 배포 워크플로가 사이트를 갱신합니다.
