SpecToPR는 하나의 스킬만 제공하는 플러그인입니다. 별도 서버를 실행하거나 데이터베이스를 만들지 않습니다.

## Codex

```bash
codex plugin marketplace add https://github.com/dhyun2/spec-to-pr --ref main
codex plugin add spec-to-pr@spec-to-pr
```

설치한 뒤 새 작업을 열면 최신 스킬을 사용할 수 있습니다.

## Claude Code

```text
/plugin marketplace add dhyun2/spec-to-pr
/plugin install spec-to-pr@spec-to-pr
```

## 설치 확인

새 작업에서 아래처럼 요청합니다.

```text
spec-to-pr 스킬로 feature 케이스를 사용해줘.
projectRoot: /absolute/path/to/project
request: 알림 설정 토글을 추가해줘
```

모델이 `case`, 대상 프로젝트 절대 경로, 구현 요청을 확인하면 준비가 된 것입니다.
