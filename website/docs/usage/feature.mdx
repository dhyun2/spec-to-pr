`feature`는 요청한 한 가지 기능과 직접 필요한 코드만 수정할 때 사용합니다. 기획서·Figma·API 문서는 있으면 참고하지만 필수는 아닙니다. 구현 전에는 기능 요청과 제공 자료를 OpenSpec 변경 문서로 정리·대조합니다.

## 입력

```yaml
case: feature
projectRoot: /absolute/path/to/project
request: 주문 상세에서 배송지 변경 버튼을 추가해줘
targetBranch: main
test: on
```

`test`를 생략하면 `off`입니다. `on`은 OpenSpec 기반 TDD, `off`는 이 작업을 위한 단위·통합 테스트를 새로 만들거나 실행하지 않는다는 뜻입니다.

## 구현 전에 OpenSpec 문서를 준비합니다

`feature`도 바로 코드를 쓰지 않습니다. 기능 요청, 제공된 API 문서·Figma, 대상 프로젝트 규칙을 `openspec/changes/<변경명>/`의 `proposal.md`, `tasks.md`, `spec.md`로 정리합니다. 확정 요구사항과 수용 시나리오, API 제약, 화면 상태, 미확정 항목을 자료와 한 줄씩 대조한 뒤 구현합니다.

## 구현 규칙

- 요구한 기능과 직접 관련된 파일만 먼저 찾습니다.
- 기존 상태 관리, API 클라이언트, 컴포넌트 규칙을 따릅니다.
- UI가 있으면 사내 디자인 시스템을 우선 사용하고, 요청한 흐름의 화면·입력·선택·확인 결과까지 구현합니다.
- 기능과 무관한 구조 변경이나 전체 프로젝트 검증을 기본으로 추가하지 않습니다.

## test: on이면 OpenSpec 기반 TDD를 합니다

확정된 OpenSpec 요구사항과 수용 시나리오를 테스트 항목으로 옮깁니다. 관련 실패 테스트를 먼저 작성하고, 최소 구현으로 통과시킨 뒤 리팩터링합니다. 대상 프로젝트의 기존 테스트 도구만 사용합니다.

`test: off` 또는 생략이면 단위·통합 테스트를 새로 만들거나 실행하지 않습니다. `test: on`인데 테스트 도구가 없거나 시나리오를 테스트로 만들 수 없다면 TDD를 했다고 쓰지 않고 Gap에 이유·영향·다음 작업을 남깁니다.

## 검증

`feature`는 `test` 값과 별개로 변경 기능만 고르는 E2E를 한 번 실행하고, 같은 사용자 흐름을 보여 주는 WebM 또는 MP4 영상 한 개를 `spec-to-pr-evidence/<변경명>/`에 남겨 PR에 연결합니다. 기존 프로젝트의 E2E 도구를 사용하며, 전체 프로젝트 E2E를 대신 실행하지 않습니다.

Figma나 승인 화면이 함께 제공된 경우에는 화면도 비교합니다. 92% 미만이면 Diff를 보고 구현을 고친 뒤 같은 조건으로 다시 비교하며, 최초 비교를 포함해 최대 3회까지 시도합니다. 기준 이미지가 없으면 `화면 기준 없음` Gap을 남기고 점수를 만들지 않습니다. E2E 영상은 화면 비교를 대신하지 않습니다.

## PR 예시

```md
## 개발한 기능

- 주문 상세에서 배송지를 변경할 수 있습니다.

## 화면 일치율

| 화면 | 비교 기준 | 비교 횟수 | 일치율 | 결과 | 증빙 |
| 배송지 변경 흐름 | 화면 기준 없음 | - | 측정하지 못함 | Gap | 구현 화면 |

## 사용한 API

| Method | Path | 사용 목적 |
| PATCH | /orders/{orderId}/shipping-address | 배송지 변경 |

## E2E 영상

- `spec-to-pr-evidence/shipping-address/change-shipping-address.webm`
  - 주문 상세 → 배송지 선택 → 저장 → 변경된 배송지 확인 흐름
  - `pnpm playwright test tests/e2e/order-shipping-address.spec.ts` 통과

## Gap

| 확인 또는 개발이 필요한 내용 | 영향 | 다음 작업 |
| 화면 기준 없음 | 낮음 | 승인 화면을 받은 뒤 비교 진행 |

## 검증

- `test: on` — OpenSpec 수용 시나리오 기반 단위 테스트 통과
- 변경 기능 E2E 1건 통과
- 사용자 흐름 영상 1개 커밋
```
