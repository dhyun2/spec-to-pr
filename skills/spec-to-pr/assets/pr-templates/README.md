# Draft PR 템플릿 선택

하나의 범용 템플릿을 재사용하지 않습니다. `case`에 맞는 파일 하나만 선택하고, 값이 없는 선택 섹션은 PR 본문에서 생략합니다.

| case      | 템플릿                | 반드시 보이는 정보                                                            |
| --------- | --------------------- | ----------------------------------------------------------------------------- |
| `legacy`  | `legacy-migration.md` | 원본→대상, 전체 화면 매트릭스, 기준·이관·Diff 이미지, 보존 이관 확인, API Gap |
| `brief`   | `brief-delivery.md`   | 요구사항 충족, 제외 범위, 화면 비교                                           |
| `feature` | `feature-flow.md`     | 사용자 흐름 영상, 변경 전후 동작, 회귀 검증, 화면 비교                        |
| `figma`   | `figma-ui.md`         | Figma 상태 매핑, 상태별 일치율, 디자인·접근성 검증                            |

Run ID, 내부 로그, 빈 체크리스트, 토큰·쿠키·개인정보는 어느 템플릿에도 넣지 않습니다.
